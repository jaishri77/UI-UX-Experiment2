# UI-UX-Experiment2

## Aim:
To design a modern mobile shopping application interface using Figma by applying UI/UX design principles such as proximity, similarity, hierarchy, figure-ground, continuity, and closure.

## Algorithm:
```
Open Figma and create a new design file.
Create mobile frames for the Splash Screen and Home Screen.
Select a suitable color palette and typography for the fashion app theme.
Design the app logo using shapes, gradients, and icons.
Create the Splash Screen with branding elements and tagline.
Design the Home Screen with:
Navigation bar
Search bar
Category buttons
Product cards
Bottom navigation menu
Use Auto Layout and alignment tools for proper spacing and consistency.
Apply UI/UX principles to improve usability and visual hierarchy.
Add icons, shadows, and interactive elements for better appearance.
Create prototype links between screens using Figma Prototype mode.
Preview and test the mobile app flow.
Export the final design screens for presentation and documentation.
```
